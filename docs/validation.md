# Проверки и состояние разработки

## Подтверждено

Пользователь подтвердил работу Mac-версии в контексте Resolume 7.16. Полная матрица macOS/Intel/аудиоустройств не проверена.

На Linux ранее прошли ASan/UBSan core/audio tests и 21 сочетание Config × Arrange в реальном OpenGL 4.1 Core через FFGL. Проверены метаданные, прозрачность, сохранение GL state, resize, очередь и обработка ошибок аудио с моделью драйвера. LeakSanitizer отключался из-за ограничений ptrace. Аппаратный микрофон в Linux-тесте не используется.

## Текущая задача

Добавить Windows x64, воспроизводимую сборку и установку, очистить структуру Git без переписывания истории. Рабочие архивы и прежние отчёты сохранены локально в игнорируемой `.local/`. Mac-рендерер и идентификатор FSAR сохраняются.

Следующий шаг: собрать Windows DLL и проверить доступные сценарии. Реальную работу WASAPI и Resolume на Windows необходимо подтвердить на Windows-машине.
