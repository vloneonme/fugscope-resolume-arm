Готовые плагины для Resolume 7 — компиляция и GitHub Actions пользователям не нужны.

- **Windows:** скачайте `FugScope-windows-x64.zip`, распакуйте и скопируйте `FugScope.dll` в папку FFGL-плагинов.
- **macOS Apple Silicon / Intel:** скачайте `FugScopeArm-universal.zip` и скопируйте целиком `FugScopeArm.bundle` в папку FFGL-плагинов.
- Добавьте папку в Preferences → Video → FFGL Plugin Directories, перезапустите Resolume, найдите источник в Sources и включите Test Signal.

Семь режимов осциллограммы, три варианта расположения, Scale/Width, прозрачный фон. Системный аудиовход: CoreAudio на Mac, WASAPI на Windows. На Windows зависимости встроены в DLL.

Проверки релиза: Windows MSVC build и core/audio/LoadLibrary tests, macOS Universal build и core/audio tests, Linux OpenGL (21 сочетание) и sanitizers. Работа Mac-версии в Resolume 7.16 подтверждена пользователем. Изображение и аппаратный аудиовход в Windows Resolume ещё требуют ручной проверки; Intel отдельно не проверен в хосте.

Mac bundle подписан ad-hoc, без Developer ID/notarization; Windows DLL не имеет Authenticode-подписи.

`FugScope-source.zip` — соответствующие исходники с зависимостями, `SHA256SUMS.txt` — контрольные суммы. GPL-3.0-only; оригинал Alex May / bigfug. Неофициальный порт.
